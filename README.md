The scene is in `Assets/Scenes/`. Select RotatingCenter to view the object controlling all yellow circles. In the script window you will see several variables.
- Layer_separation_pt controls the separation between two adjacent layers, in pixels.
- Number_of_layers controls how many layers you wish there to be.
- Number_per_layer controls how many yellow circles will appear in one layer.
- Speed controls the yellow circles' linear **or** angular speed.
- Linear_angular controls whether to use the `Speed` field as linear or angular speed.
- Center_obj is the object which is centered by the yellow circles.

Use arrow keys to move the white square to avoid yellow circles. You may also use E key to change the square's color if you wish. Use R to reset the scene.
